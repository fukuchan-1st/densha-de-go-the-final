# v118 supplied Isesaki BVE2 control import

`python tools/parse-isesaki118.py` regenerates `dist/assets/final/tobu118-bve2-profile.json` from `OneDrive/Desktop/isesaki/isesaki/Route/東武伊勢崎線/35 快速.csv` (CP932). Only this new JSON is written. No source sound file, sound reference, train selection, or arrival/departure clock is imported. Current simulator timetables/PMSM sounds remain authoritative.

The representative file covers 浅草→会津田島: first stop absolute 100225 m, last stop 290825 m, 190600 m between stops. 73 Sta entries include historic 鬼怒立岩信号場; 東武ワールドスクウェア is absent. 業平橋 becomes とうきょうスカイツリー and 松原団地 becomes 獨協大学前〈草加松原〉. Modern 上今市/東武日光 branch stations are outside this representative route. Other services are intentionally not reimported.

All JSON chainage is relative to the Asakusa stopping point (`source.originAbsoluteM=100225`); add it to recover original CSV distances. `stations[].declaredS` is Sta placement, `stopS` is the associated stopping marker. Use `anchorsByRoute` and stopping positions for a piecewise chainage warp onto current OSM routes, preserving their horizontal coordinates and geographic building/water alignment. Missing modern World Square uses the surrounding anchors. Historical station/layout positions remain historical approximations.

Main collections: `grades[{s,permille}]`, `curves[{s,radius,cantMm}]`, `limits[{sStart,sEnd,kmh,post,direction}]`, `heightGround[{s,railAboveGroundM}]`, `ground[{s,index}]`, `railSpans[{railIndex,sStart,sEnd,knots,types}]`, `forms`, `signals`, `platformObjects` and selected bridge/station `landmarkPlacements`. Each form covers one source25m block; most include resolved `edges:[[s,left,right],…]`, `surfaceHeight:[[s,y],…]`, `boarding`, and `roofPresent`. `stations[].forms` indexes nearby form rows. Platform bounds use actual AddVertex values from the supplied form CSVs, not imported textures. No optional landmark mesh was converted; references/placements are metadata only.

Semantics checked against [openBVE CSV documentation](https://openbve-project.net/documentation_hugo/en/routes/csv.html): negative Curve radius turns left, positive right; cant is millimetres. Pitch is per mille. Rail X/Y are right/up offsets; omitted values retain previous state. Rail position updates deform the preceding25m block, rather than interpolating continuously from arbitrarily distant commands. Limit0 releases the restriction; its directional parameter only changes the post arrow. Form L/R indicates an outside platform, numeric rail2 spans between rails. Roof index0 means no roof.

Source `Track.Height` is rail-to-ground separation, not train elevation. Asakusa source Height is6m. It must not be added to existing rail elevation as a second lift. This is the author's model setting, not a survey of the station building height.

Important vertical limitation: source Pitch omits much of the Nikko approach climb. Its integrated rail height at 下今市 is -13.74676m and 会津田島 +170.10190m relative to Asakusa, while the current GSI profile has the real mountain climb. `stations[].integratedRailHeightM` is provided for diagnosis only. Keep current DEM station elevations and use source grades for local shape with endpoint correction; do not replace whole-route vertical geometry with the BVE integral. Existing supplied yagan BVE controls may be preferable to this older whole-route file there.

`stations[].pass` and `doorSide` describe source rapid35: passing stations often have doors none. They must not override the currently selected service's stop pattern; use actual platform forms to derive boarding sides for other services. Decorative null rails (type3→null.csv) and remote placement rails are retained as source control metadata, so filter them before drawing physical tracks.
