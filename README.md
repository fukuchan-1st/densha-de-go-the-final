# 東北本線 701系運転プロトタイプ

黒磯→高久→黒田原→豊原→白坂→新白河、22.1kmを走るブラウザー用3Dシミュレーターです。

## 起動

Windowsでは「起動する.cmd」をダブルクリックしてください。Pythonが必要です。ローカルの http://127.0.0.1:8765 をブラウザーで開きます。終了はサーバーのウィンドウを閉じてください。インターネット接続不要です。

開発用：このフォルダーで `npm start`。検証は `npm test`。

## 表示

メニュー・運転画面を含め1600×900の16:9固定レイアウトを均等拡大縮小し、画面の比率が異なる場合は上下または左右に黒帯を表示。前方の力行・制動案内カードを廃止し、操作結果は下部に表示。映像の右端ぴったりに細い停止位置バーを表示。明るい緑の帯が±10m、黄色地・赤枠のひし形が自車位置で、上側が行き過ぎ・下側が手前、中央が停止位置です。停車判定も±10m。

## 操作

|キー|操作|
|---|---|
|S / ↓|マスコンをP5方向へ1段|
|W / ↑|マスコンをEB方向へ1段|
|X|惰行 N|
|Space|非常 EB|
|O|戸開・戸閉|
|Esc|一時停止|

力行P1〜P5、ブレーキB1〜B7・非常。停止位置±10m・速度ほぼ0で戸開可能、5秒乗降後に戸閉で次駅へ。行き過ぎは前駅から再開。終点で全行程の結果を表示します。停車アシスト・時間倍率1/3/10・前面展望・音量調整もあります。

## データ・再現の範囲

- トップ画面：ユーザー提供のJR-east-701-1500(F2-510).jpgを直接使用。生成画像のレイアウトをHTMLで再構成。
- 駅間距離：[RailLab](https://raillab.jp/transport/39)の4.0 / 4.2 / 5.2 / 5.3 / 3.4km。
- 車両性能：[指定のWikipedia記事](https://ja.wikipedia.org/wiki/JR東日本701系電車)の701系共通諸元を1500番台の基準として採用。起動2.1km/h/s、常用・非常3.6km/h/s、最高110km/h。記事内に独立した1500番台の速度別引張力曲線はないため、高速域の低下・走行抵抗・各ノッチ配分は試作の仮定。
- 線路：[OpenStreetMap](https://www.openstreetmap.org/copyright)の在来線本線座標293点。駅間ごとに営業キロへ校正。3Dは非等間隔3次Hermite補間、表示曲線半径は接線差からの近似。測量による正確な曲線半径ではありません。平面形状の詳細はroute-geometry-notes.md、BVEから追加した縦断線形の詳細はbve-profile-notes.md。
- 走行音：提供701soundpack.zipをコピー・展開し、RTM元スクリプトの区分線形ピッチ・音量とノッチ別フェードをWeb Audioへ移植。詳細はsound-analysis.md。30 OGGを使用。動画2本は参考URLを記録しましたが、聴取比較による補正は未実施です。
- 参考動画：[初回](https://www.youtube.com/watch?v=mt_LGUlqzoY)、[追加の優先参考](https://www.youtube.com/watch?v=sspn7X1b_0k)。動画音声のコピーや差し替えはしていません。
- 景色・建物・駅構内・信号は簡略3D表現。運転台は追加のユーザー写真を参考に、白い丸形計器と左右レバーを再配置。木・低木・穂付き草は枝葉の透過テクスチャを用い、地面・砂利・畑は手続き生成の細部模様を使用。勾配と常設速度制限は提供BVEデータから移植。実カント、正確な分岐器、信号連動・ATS-Ps・ダイヤは未実装。制限は運転者が守る方式で、超過時に表示が赤くなります。信号速度、列車後端による解除条件は未再現です。停止位置は地図駅位置を基準にした試作位置です。黒磯で701系を運転する体験用で、現在の営業運転の再現ではありません。

## BVE勾配・速度制限

ユーザー提供の東北本線4129Mシナリオから81勾配点・43速度切替点を抽出。元はE531系用なので、曲線の＋10km/hは外し、基準標識値に701系の上限110km/hを適用。勾配は−10〜＋12‰。駅間距離が元BVEと異なるため、6駅を合わせて区間ごとに位置換算。線路・架線・植生の高さもこの勾配に追従します。実路線を測量した線形ではありません。

上りでは `a = a_flat − 9.80665 × 勾配‰ / √(1000000 + 勾配‰²)` で重力ぶん加速を弱め、下りでは逆に加速が増えます。勾配遷移は線形補間し、積分して相対高さを計算。BVEエンジン内部の厳密な縦曲線の再現ではありません。

## 計算をかんたんに言うと

毎秒、列車の速さを「加速ぶん足す・ブレーキぶん引く」で更新。その速さから進んだ距離を計算します。音は速度表の2点の間をなめらかにつないで、「いまの速さならどの高さ・大きさか」を求めています。

詳しい式は `dist/physics.js` と `sound-analysis.md`、地図計算は `route-geometry-notes.md` を参照してください。

## BVE主要構造物

提供BVEの配置・繰返し命令と参照モデルの存在を確認し、トンネル1区間、鉄橋2区間、道路跨線橋1件、高久の駅跨線橋1件、切通し1区間、川1区間を追加。位置をRailLab距離へ合わせています。元のモデル・テクスチャをそのまま再生する形式ではなく、位置・寸法を参考にした簡略3Dです。詳細はbve-structures-notes.md。

トンネルは黒磯起点17.531〜17.750km。単線の坑門と内壁を配置し、内部では照明を暗くしています。低い架線を追加し、屋外の架線柱や植物が内部に入らないよう調整。周囲の盛土・坑口の外観は試作の補完表現です。鉄橋区間では地面を開けて橋桁を見せ、明示された最初の川だけを配置しています。

停車アシストは勾配の切替で行き過ぎないよう保守的な減速目標を使い、±10m外からの位置補正はしません。
